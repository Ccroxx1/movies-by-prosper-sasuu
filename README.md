# Movies By Prosper Sasuu

**Movies By Prosper Sasuu** is a modern, responsive movie discovery platform designed for finding HD and 4K movies. It provides a clean UI for browsing latest releases, trending titles, and top-rated films, with advanced filtering options.

![Project Preview](icons/logo-full.png)

## 🚀 Features

- **Advanced Search & Filtering:** Filter by genre, quality (720p, 1080p, 4K), rating, year, and language.
- **Watchlist:** Save your favorite movies to a local watchlist (persisted in your browser).
- **Recently Viewed:** Quickly pick up where you left off with a "Recently Viewed" strip.
- **PWA Ready:** Installable as a progressive web app on mobile and desktop.
- **Dark & Light Mode:** Seamlessly toggle between dark and light themes.
- **Responsive Design:** Optimized for mobile phones, tablets, and desktop displays.
- **Deep Linking:** Direct links to movie details for easy sharing.
- **Rich Metadata:** View trailers, cast, characters, and high-quality screenshots.

## 🛠️ Technology Stack

- **Frontend:** HTML5, CSS3 (Custom Properties, Flexbox, Grid), Vanilla JavaScript.
- **PWA:** Service Workers for offline caching and installability.
- **API:** Fetches movie data from the [Accel-li API](https://movies-api.accel.li).
- **Deployment:** Optimized for Vercel, Netlify, or standard Nginx/Apache hosting.

## 📦 Setup & Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/prospersasuu/MoviesByProsperSasuu-redesign.git
   ```
2. **Open the project:**
   Simply open `index.html` in your favorite browser, or serve it using a local development server (e.g., Live Server in VS Code).
